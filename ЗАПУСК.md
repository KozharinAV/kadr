# Запуск

Нужны Docker и Docker Compose. Из корня репозитория:

```bash
docker compose up --build -d
```

Первая сборка занимает несколько минут: ставятся зависимости, собираются API, воркер и интерфейс. Когда команда завершится, откройте http://localhost:18088.

Вход администратора: `admin@kadr.local` / `Admin123!`. Учётная запись создаётся при первом старте API.

Проверка API: http://localhost:13100/api/health — ответ `200`.

Остановка:

```bash
docker compose down
```

База и загруженные файлы остаются в томах Docker. Команда `docker compose down -v` удаляет эти данные.

## Адреса

| Что | Адрес |
| --- | --- |
| Интерфейс | http://localhost:18088 |
| API | http://localhost:13100/api/health |
| Консоль хранилища | http://localhost:19101 (`kadr` / `kadrsecret`) |
| Метрики воркера | http://localhost:13011/metrics |
| Prometheus | http://localhost:19090 |
| Grafana | http://localhost:13030/d/kadr/kadr (`admin` / `admin`) |

Порты на хосте сдвинуты, чтобы не пересечься с другими локальными сервисами.

## Загрузка ролика

Кнопка «Загрузить» открывает проводник. После выбора одного или нескольких файлов появляется окно настроек. Для каждого файла задаются имя, качество, поворот на 90°, удаление звука и секунда кадра превью. В очередь ролик уходит по кнопке «Загрузить» в этом окне.

Качество: высокое — высота 1080, обычное — 720, экономичное — 480. Если исходник ниже выбранной высоты, он не увеличивается. Подходят mp4, webm, mov и mkv до 200 МБ.

Пользователи и роли — на вкладке «Пользователи».
