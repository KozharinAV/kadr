# Интерфейс

Веб-интерфейс сервиса «Кадр»: вход, библиотека роликов, просмотр, загрузка с настройками обработки и управление пользователями.

Интерфейс на Angular. Экраны библиотеки и пользователей обновляют данные по мере обработки. Тексты доступны на русском и английском языках.

Запуск всего сервиса описан в [ЗАПУСК.md](../ЗАПУСК.md).

Отдельно, когда API уже запущен:

```bash
npm start
```

Интерфейс открывается на http://localhost:4200. Запросы `/api` уходят на http://localhost:13100.

```bash
npm run build
npm test
npm run lint
```
