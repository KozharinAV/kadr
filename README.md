# Кадр

Сервис загрузки и обработки видео.

Редактор загружает ролик. API сохраняет оригинал в объектное хранилище и ставит задачу в очередь. Отдельный процесс-воркер через FFmpeg готовит mp4 для просмотра и JPEG-превью. Зритель смотрит готовые ролики. Администратор управляет пользователями и видит все статусы обработки.

## Возможности

- Загрузка одного или нескольких файлов: mp4, webm, mov, mkv до 200 МБ.
- Перед постановкой в очередь для каждого файла задаются имя, качество, поворот на 90°, удаление звука и секунда кадра превью.
- Качество: высокое (1080), обычное (720), экономичное (480). Исходник ниже выбранной высоты не увеличивается.
- Поиск по имени, просмотр и удаление одного или нескольких роликов.
- Интерфейс на русском и английском языках.

## Роли

| Роль | Доступ |
| --- | --- |
| Зритель | Готовые ролики |
| Редактор | Свои ролики в любом статусе и чужие готовые, загрузка и удаление своих |
| Администратор | Все ролики, повтор упавшей обработки, пользователи и роли |

## Состав

- `kadr-front` — веб-интерфейс.
- `kadr-back` — HTTP API и воркер очереди.
- PostgreSQL, Redis, объектное хранилище, Nginx, Prometheus и Grafana поднимаются вместе с сервисом.

API принимает запросы и ставит задачи в очередь. Воркер забирает задачи и не обслуживает HTTP. Схема базы меняется миграциями.
